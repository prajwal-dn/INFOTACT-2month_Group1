# Day 9 — CAN-Sentinel Desktop Dashboard
Date: 28 October 2026

## Objective
Build a desktop interface for analyzing saved virtual-CAN captures
using the existing Isolation Forest inference pipeline.

## Implementation

Created `src/dashboard.py` using PySide6.

The dashboard provides:
- Three preset captures: normal baseline, high-frequency attack,
  and unexpected extended CAN ID
- A file browser for selecting other saved CAN CSV captures
- An Analyze Capture action that runs saved-model inference
- Summary cards for windows scored, normal windows, anomalous
  windows, and anomaly rate
- A results table with window timestamps, frame counts, unique
  CAN IDs, extended-frame counts, predictions, and anomaly scores
- A CSV report generated by the inference script

The analysis runs in a worker thread so the interface remains
responsive while processing a capture.

## Run the Dashboard

Create and activate the project virtual environment, then install
the project dependencies:

`python3 -m venv .venv`

`source .venv/bin/activate`

`python -m pip install -r requirements.txt`

Launch the application:

`python src/dashboard.py`

Select a preset or browse to a saved CAN sniffer CSV, then click
**Analyze capture**.

## Limitations

This is an offline analysis dashboard for saved CAN captures.
It does not yet monitor a live CAN stream or connect to a physical
vehicle network.

The normal baseline produced one anomalous window in the current
experiment. The two simulated attack captures were fully flagged
in the tested windows. These results are preliminary and are not
independently validated real-world accuracy.
